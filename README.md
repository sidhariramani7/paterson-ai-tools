# Paterson AI Tools

Three production tools built using Claude Code for Paterson Capital. No dev team. All live.

---

## 1. AI Research Blog Pipeline

**What it does**
Takes Paterson's raw research and analyst reports, automatically converts them into SEO-first, brand-consistent articles, publishes them to the website, and distributes a formatted copy to the sales and RM team every morning.

**Why it matters**
Paterson publishes daily market research. The old process: research sits in PDFs, never reaches the website or clients. The new process: fully automated, zero manual effort, consistent output every day.

**Stats**
- 1,000+ articles published to date
- ~5 articles per day
- Zero manual effort after setup

🔗 [patersoncapital.com/blog](https://patersoncapital.com/blog)

---

## 2. IPO Dashboard

**What it does**
A live IPO tracker showing upcoming, open, and recently listed IPOs — with allotment status, GMP data, subscription numbers, and key dates. Auto-updates daily from NSE data.

**Why it matters**
IPO-related searches are Paterson's highest-traffic opportunity. The dashboard captures intent at the moment people are actively looking, and converts it into enquiries.

🔗 [patersoncapital.com/ipo](https://patersoncapital.com/ipo)

---

## 3. Hiring Engine

**What it does**
Custom careers page with live job listings, role-specific application forms, and a backend wired to Google Sheets for the HR team to manage applications without any additional tooling.

**Why it matters**
Replaced a static "email us your CV" page with a structured hiring flow — better candidate experience, zero recruitment software cost.

🔗 [patersoncapital.com/careers](https://patersoncapital.com/careers)
